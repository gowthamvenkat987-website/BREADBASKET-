# The Bread Basket Vijayawada 🥐🎂

A modern, production-quality website and online ordering platform for **The Bread Basket Vijayawada** — an artisanal bakery and cake shop on Panta Kaluva Road, Vijayawada, Andhra Pradesh.

![The Bread Basket Vijayawada](https://images.unsplash.com/photo-1578985545062-69928b1d9587?auto=format&fit=crop&w=1200&q=80)

---

## 🌟 Features

- **🏠 Home Page**: Hero banner, announcement bar, 4.3★ Google review badge (960+ reviews), featured categories, best-seller items, "Why Choose Us", customer testimonials, and Google Maps preview.
- **🥐 Full Menu Page**: 8 categories (Cakes, Pastries, Artisan Breads, Cookies, Desserts, Sandwiches, Pizza, Beverages), real-time search, eggless/pure veg filters, price and popularity sorting.
- **🎂 Interactive Custom Cake Atelier**: Real-time interactive cake visualizer with dynamic shapes (Round, Heart, Square, 2-Tier), flavor colors, gourmet toppings, and calligraphy text message dynamically rendered directly on the cake preview.
- **🍰 Product Details Page**: Dynamic weight pricing (0.5 kg, 1 kg, 1.5 kg, 2 kg), ingredients breakdown, allergen warnings, 1-click Add to Basket, and Buy Now.
- **🛒 Shopping Basket**: Persistent cart using `localStorage`, weight variants, quantity modifiers, free delivery progress indicator, and coupon system (`WELCOME50`, `BREAD10`, `VIJAYAWADA`).
- **💳 Checkout Flow**: Express Vijayawada Delivery vs Store Pickup toggle, address validation, Cash on Delivery, simulated UPI QR code, and celebratory order confirmation screen with WhatsApp tracking.
- **☕ Table Reservation**: Cafe lounge reservation form with seating zone preferences, guest counts, and booking reference modal.
- **📖 About Us**: The story of The Bread Basket Vijayawada since 2018, slow-fermented sourdoughs, pure European butter, and chef profiles.
- **⭐ Customer Reviews**: 4.3/5 rating overview, breakdown bars across 960+ reviews, star filters, and interactive "Write a Review" modal.
- **📍 Contact Page**: Full address, opening hours (8:00 AM – 10:30 PM), interactive Google Maps embed, and direct Call/WhatsApp links.
- **🛡️ Bakery Admin Dashboard**: Overview KPIs (Revenue, Orders, Products, Reservations, Custom Cakes), live order status switcher (`Pending` ➔ `Preparing` ➔ `Out for Delivery` ➔ `Completed`), product catalog manager (Add/Edit/Delete), and 1-click demo data reset.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + Vanilla CSS
- **Routing**: React Router v7
- **Icons**: Lucide React
- **Animations / Effects**: Canvas Confetti
- **State & Persistence**: React Context API + LocalStorage

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/gowthamvenkat987-website/BREADBASKET-.git
cd BREADBASKET-
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
npm run preview
```
